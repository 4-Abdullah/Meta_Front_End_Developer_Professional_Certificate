# Abdullah Malik Sher | 3D Portfolio (Next.js)

Next.js 14 (App Router) + TypeScript + three.js.

## Run
    npm install
    npm run dev       # http://localhost:3000

## Deploy
Push to GitHub and import the repo in Vercel (no config needed).

## Edit content
All text lives in `lib/data.ts`. The 3D scene is `components/Scene.tsx`.
Colors and layout are in `app/globals.css` (CSS variables at the top).
